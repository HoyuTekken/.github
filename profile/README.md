# 朋優学院高等学校 鉄道研究部 (HoyuTekken)

## 部活紹介 / About Us

朋優学院高等学校 鉄道研究部（HoyuTekken）の公式GitHubアカウントです。

私たちの学校は、**JR線・東急線・都営線**の3方に囲まれた、鉄道ファンにとって最高のロケーションに位置しています。
当部活では、メンバー間のコミュニケーションを大切にしながら、鉄道を通じて地理や歴史など総合的な探求心を育むことを目的に活動しています。

旅行好き、写真好き、ジオラマ（模型）好きなど、「ちょっと鉄道に興味がある」という**鉄分少なめの方も大歓迎**です！好きなことに没頭し、充実した高校生活を一緒に送りましょう！
